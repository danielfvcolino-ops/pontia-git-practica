# pontia-git-practica

Práctica del **Módulo 1: Versionado de Código y Colaboración** del programa
Intensivo de IA Avanzada y Generativa de PontiaTech.

Este repositorio contiene los ejercicios de git y GitHub del módulo:

- Creación y configuración del repositorio
- Protección de la rama `main` y trabajo con Pull Requests
- Uso de `.gitignore`
- Creación de ramas y resolución de conflictos
- Automatización con GitHub Actions
